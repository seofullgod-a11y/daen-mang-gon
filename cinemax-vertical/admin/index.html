🔴 ไลฟ์พรีเมียร์

เปิดไลฟ์ = หน้าแรกของผู้ชมทุกคนขึ้นแบนเนอร์ "LIVE กำลังไลฟ์" (มีนับถอยหลังถ้าตั้งเวลาล่วงหน้า) กดเข้าไปเจอจอไลฟ์เต็มจอ: วิดีโอเล่นตรงตำแหน่งเดียวกันทุกคนตามเวลาเริ่มจริง (เลื่อน/หยุดไม่ได้เหมือนไลฟ์แท้ๆ) + แชทสด + หัวใจลอย + ยอดผู้ชมเรียลไทม์

💡 ทริค: ตั้งเวลาล่วงหน้า 1-2 ชม. แล้วโพสต์ลิงก์เว็บลงโซเชียล — ผู้ชมจะเห็นนับถอยหลังในหน้าแรก สร้างกระแสรอดูพร้อมกัน

แท็ก / หมวดหมู่

แท็กมาจาก 2 ช่องของแต่ละเรื่อง: แนว (คั่นด้วย ·) และ คีย์เวิร์ด SEO (คั่นด้วย , ) — ผู้ชมกดแท็กในหน้าเล่น/หน้ารายละเอียดแล้วจะเปิดหน้าหมวด ?t=แท็ก ซึ่ง Google เก็บเข้า index ได้ · เปลี่ยนชื่อ/ลบที่นี่ = แก้ให้ทุกเรื่องที่ใช้แท็กนั้นพร้อมกัน

คอมเมนต์ล่าสุด

SEO / ตั้งค่าเว็บ

Meta หลักของเว็บ (มีผลทั้งเว็บทันที)

Sitemap

สร้าง sitemap.xml จาก หน้าแรก + ทุกเรื่อง (?m=) + ทุกบทความ (?a=) + ทุกหมวดหมู่ (?t=) แล้วนำไฟล์ไปวางที่ root ของ repo (คู่กับ index.html) จากนั้น submit ใน Google Search Console

robots.txt

ไฟล์ robots.txt อยู่ที่ root ของ repo แล้ว — เปิดดูและแก้บรรทัด Sitemap: ให้ตรงโดเมนของคุณ (อนุญาตเก็บทุกหน้า ยกเว้น /admin/)

สำรอง / กู้คืนข้อมูล

⬇ สำรองข้อมูล (Export)

ดาวน์โหลดข้อมูลเก็บไว้เป็นไฟล์ JSON — ทำเป็นประจำก่อนแก้อะไรเยอะๆ

⬆ กู้คืน (Import หนัง/ซีรีส์)

เลือกไฟล์ JSON ที่เคย export ไว้ — ระบบจะอัปเดตเรื่องที่มีอยู่และเพิ่มเรื่องที่หายไป (upsert ไม่ลบของเดิม)
