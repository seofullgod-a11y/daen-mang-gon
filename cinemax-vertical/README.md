# CineMax Vertical 🎬📱

เว็บดูซีรีส์สั้น**แนวตั้ง**สไตล์จีน — **เวอร์ชันใช้งานจริง** เชื่อมต่อ Supabase + เล่นวิดีโอจริง
รองรับทุกอุปกรณ์: มือถือ / iPad / คอมพิวเตอร์

## ใช้งานได้จริงยังไง

- **ข้อมูลหนัง/ซีรีส์** โหลดจาก Supabase ตาราง `movies` (โปรเจกต์เดียวกับเว็บเดิม — เพิ่ม/แก้หนังจากหลังบ้านเว็บเดิมได้เลย ข้อมูลจะมาแสดงที่นี่อัตโนมัติ)
- **ตอนซีรีส์** โหลดจากตาราง `episodes` (season / episode / video_url)
- **เล่นวิดีโอจริง** รองรับ: Cloudflare Stream, YouTube, ไฟล์ HLS (.m3u8 เช่น Bunny), MP4 ตรง, Google Drive
- **ดูต่อจากที่ค้าง** จำตอน + วินาทีที่ดูค้าง (localStorage) เปิดมาดูต่อได้เลย
- **รายการโปรด / ถูกใจ** เก็บในเครื่องผู้ใช้
- **แชร์** ลิงก์เปิดตรงเข้าเรื่องนั้น (`/#movieId`)
- **โหมดตัวอย่าง** ถ้าต่อฐานข้อมูลไม่ได้ จะแสดงข้อมูลจำลองพร้อมแบนเนอร์เตือน (เว็บไม่ล่ม)

## Responsive 3 ระดับ

| จอ | การแสดงผล |
|---|---|
| มือถือ (≤740px) | เต็มจอ, เมนูล่าง 5 ปุ่ม, กริด 3 คอลัมน์ |
| iPad (741–1100px) | กริดอัตโนมัติ 4–5 คอลัมน์, hero 2 ใบ, เมนูล่างเหมือนมือถือ |
| คอม (≥1101px) | เมนูบน (ไม่มีเมนูล่าง), กริด 6–7 คอลัมน์, player เป็นคอลัมน์ 9:16 กลางจอ + ปุ่มด้านขวา, คีย์ลัด: ↑↓ เปลี่ยนตอน · Space หยุด/เล่น · M ปิด/เปิดเสียง · Esc ปิด |

## กติกาเลือกวิธีเล่น (js/06-player.js → classify)

| URL | วิธีเล่น |
|---|---|
| `*.m3u8` (Bunny, CF HLS) | native `<video>` + hls.js — ควบคุมเต็ม, จำวินาทีที่ค้าง, จบตอนแล้วเลื่อนตอนถัดไปอัตโนมัติ |
| `*.mp4 / .webm / .mov` | native `<video>` เช่นกัน |
| `cloudflarestream.com / videodelivery.net` | iframe embed ของ Cloudflare |
| YouTube ทุกรูปแบบ (watch/shorts/youtu.be) | iframe youtube-nocookie |
| Google Drive | iframe `/preview` |

> 💡 **แนะนำ:** ถ้าอยากได้ประสบการณ์แนวตั้งเต็มรูปแบบ (จำวินาที + auto-next + tap หยุด/เล่น)
> ให้ใส่ลิงก์แบบ **HLS `.m3u8`** ของ Cloudflare Stream (`https://customer-XXXX.cloudflarestream.com/VIDEO_ID/manifest/video.m3u8`)
> แทนลิงก์ iframe — หาได้จาก Cloudflare Dashboard → Stream → วิดีโอ → HLS Manifest URL

## การ Deploy

เป็น static site ล้วน ไม่ต้อง build — อัปโหลดขึ้นที่ไหนก็ได้:

- **โฮสต์เดิม (Apache)**: อัปทั้งโฟลเดอร์ขึ้น web root หรือโฟลเดอร์ย่อย เปิดได้ทันที
- **GitHub Pages**: push ขึ้น repo → Settings → Pages → เลือก branch → เสร็จ
- ไม่ต้องใช้ PHP (เวอร์ชันนี้อ่านอย่างเดียว ไม่มีหลังบ้านในตัว)

### สิ่งที่ต้องตรวจฝั่ง Cloudflare Stream

ถ้าวิดีโอไม่เล่น ให้เช็ก **Allowed Origins** ของ Stream:
Cloudflare Dashboard → Stream → Settings → Allowed Origins — ต้องมีโดเมนใหม่ที่ deploy (เช่น `romazeed1.info`, `*.github.io`) หรือปล่อยว่าง (อนุญาตทุกโดเมน)

### สิ่งที่ต้องตรวจฝั่ง Supabase

- ตาราง `movies` และ `episodes` ต้องเปิด RLS ให้ **anon อ่านได้** (SELECT) — ถ้าเว็บเดิมใช้งานได้อยู่แล้ว แปลว่าตั้งไว้ถูกแล้ว
- key ที่อยู่ใน `02-config.js` เป็น anon key (public read) เปิดเผยได้ตามดีไซน์ของ Supabase — **ห้าม**เอา service_role key มาใส่เด็ดขาด

## การจัดการเนื้อหา

เวอร์ชันนี้เป็น "หน้าเว็บผู้ชม" — เพิ่ม/แก้หนัง, อัปโหลดวิดีโอขึ้น Cloudflare, จัดการตอน
ให้ทำผ่าน**หลังบ้านของเว็บเดิม**ตามปกติ ข้อมูลจะแสดงที่นี่อัตโนมัติ (แชร์ฐานข้อมูลเดียวกัน)
