# CineMax Vertical 🎬📱

เว็บดูซีรีส์สั้น**แนวตั้ง**สไตล์จีน (short drama / 短剧) — ดีไซน์ mobile-first เลื่อนขึ้น-ลงดูเป็นตอนแบบ ReelShort/DramaBox

> ⚠️ **สถานะ: Prototype (UI เท่านั้น)** — ใช้ข้อมูลตัวอย่าง (mock data) โปสเตอร์เป็นสีไล่เฉด
> ยังไม่ได้เชื่อมต่อ Supabase / Cloudflare Stream ของจริง

---

## โครงสร้างโปรเจกต์

```
cinemax-vertical/
├── index.html          # โครง HTML ทุกหน้า (โหลด css/js ภายนอก)
├── css/
│   └── styles.css      # สไตล์ทั้งหมด (โทนดำลึก·แดงชาด·ทองแชมเปญ)
└── js/                 # โหลดเรียงตามเลขหน้าไฟล์ (ห้ามสลับลำดับ)
    ├── 01-icons.js         # ชุดไอคอน SVG (inline ทั้งหมด)
    ├── 02-data.js          # mock data: หมวด, รายชื่อเรื่อง, ตัวสร้างโปสเตอร์
    ├── 03-home.js          # render หน้าแรก: hero, ดูต่อ, อันดับ, กริด, ชาร์ต
    ├── 04-nav.js           # การสลับหน้า (หน้าแรก/ชาร์ต/ค้นหา/ฉัน)
    ├── 05-player.js        # โหมดเล่นแนวตั้ง 9:16 เลื่อนเปลี่ยนตอน + ไลก์/แชร์
    └── 06-sheet.js         # bottom sheet เลือกตอน + ระบบล็อกตอน (เหรียญ)
```

## ฟีเจอร์ในดีไซน์

- **หน้าแรก** — hero carousel, แถว "ดูต่อจากที่ค้าง" พร้อม progress bar, อันดับยอดฮิต (เลขทอง/แดง gradient), กริดโปสเตอร์แนวตั้ง 2:3, แท็บหมวดสไตล์จีน (เจ้าสัว/CEO, แค้นล้างแค้น, สวมรอย ฯลฯ)
- **โหมดเล่นแนวตั้ง** — เต็มจอ 9:16 เลื่อนขึ้น-ลงเปลี่ยนตอนแบบ TikTok, แถบปุ่มขวา (ไลก์+หัวใจเด้ง, คอมเมนต์, บันทึก, เลือกตอน, แชร์), แคปชันเรื่องย่อ, แตะกลางจอหยุด/เล่น
- **เลือกตอน** — bottom sheet ตารางตอน, ตอนท้ายๆ ล็อก 🔒 ปลดล็อกด้วยเหรียญ (โมเดลแอปจีน)
- **โปรไฟล์** — การ์ด VIP มีแสง shimmer, ระบบเหรียญ, สถิติการดู

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้อง build ไม่ต้องติดตั้งอะไร
(ฟอนต์ Kanit/Noto Sans Thai โหลดจาก Google Fonts — ต้องมีอินเทอร์เน็ต)

บนจอคอมจะแสดงเป็นกรอบมือถือตรงกลาง บนมือถือจะเต็มจอพอดี

## ขั้นต่อไป (ยังไม่ได้ทำ)

- เชื่อม **Supabase** (ตาราง movies) แทน mock data ใน `02-data.js`
- เชื่อม **Cloudflare Stream** ในโหมดเล่น (แทนฉากสีไล่เฉดใน `05-player.js`)
- ระบบสมาชิก / เหรียญ / ปลดล็อกตอนของจริง
- หลังบ้าน Admin (อัปโหลดวิดีโอ, จัดการตอน, ซับไตเติล)

> โปรเจกต์เดิม (แนวนอน) อยู่ในโครงสร้างไฟล์เดียวกันนี้ สามารถ merge ระบบ Supabase/Cloudflare
> จากโค้ดเดิมเข้ากับ UI ใหม่นี้ได้
