# CineMax Vertical 🎬📱

เว็บดูซีรีส์สั้น**แนวตั้ง**สไตล์จีน — **เวอร์ชันใช้งานจริง** เชื่อมต่อ Supabase + เล่นวิดีโอจริง
รองรับทุกอุปกรณ์: มือถือ / iPad / คอมพิวเตอร์

## ใช้งานได้จริงยังไง

- **ข้อมูลหนัง/ซีรีส์** โหลดจาก Supabase ตาราง `movies` (โปรเจกต์เดียวกับเว็บเดิม — เพิ่ม/แก้หนังจากหลังบ้านเว็บเดิมได้เลย ข้อมูลจะมาแสดงที่นี่อัตโนมัติ)
- **ตอนซีรีส์** โหลดจากตาราง `episodes` (season / episode / video_url)
- **เล่นวิดีโอจริง** รองรับ: Cloudflare Stream, YouTube, ไฟล์ HLS (.m3u8 เช่น Bunny), MP4 ตรง, Google Drive
- **ดูต่อจากที่ค้าง** จำตอน + วินาทีที่ดูค้าง (localStorage) เปิดมาดูต่อได้เลย
- **รายการโปรด / ถูกใจ** เก็บในเครื่องผู้ใช้
- **แชร์** ลิงก์เปิดตรงเข้าเรื่องนั้น (`/?m=movieId` — เป็น query URL ที่ Google เก็บเข้า index ได้)
- **โหมดตัวอย่าง** ถ้าต่อฐานข้อมูลไม่ได้ จะแสดงข้อมูลจำลองพร้อมแบนเนอร์เตือน (เว็บไม่ล่ม)

## ⚡ ติดตั้งฐานข้อมูล (รัน `sql/setup.sql` ใหม่ทุกครั้งที่อัปเดตเวอร์ชัน)

เปิด **Supabase Dashboard → SQL Editor** → วางเนื้อหาไฟล์ `sql/setup.sql` ทั้งไฟล์ → กด **Run**
(รันซ้ำได้ปลอดภัย — ตารางที่มีอยู่แล้วจะไม่ถูกลบ) จะได้:

- `stats` — ยอดวิว/ถูกใจจริง (ผู้ชมเพิ่มได้ทีละ +1 ผ่านฟังก์ชันเท่านั้น ปลอมตัวเลขไม่ได้)
- `comments` — คอมเมนต์ใต้ตอน
- `articles` — **บทความ SEO** ท้ายหน้าแรก (เขียนจากหลังบ้าน `/admin`)
- `settings` — **ตั้งค่า SEO ทั้งเว็บ** (title / description / keywords / ภาพ OG / URL เว็บ)

ถ้ายังไม่รัน SQL เว็บก็ยังทำงานปกติ แค่ฟีเจอร์พวกนี้ไม่แสดง

## 🔍 SEO (เวอร์ชัน 3.1)

**ความเร็วมาก่อนเสมอ** — สิ่งที่ทำในเวอร์ชันนี้:

- **Lazy render แบบเข้มงวด**: ส่วนที่อยู่ใต้จอ (Top10 ถ้าไม่โผล่, กริดใหม่ล่าสุด, กริดแนะนำ, บทความ, หน้าสำรวจ, ชาร์ต) จะ**ไม่สร้าง DOM เลยแม้แต่นิดเดียว**จนกว่าขอบ section จะโผล่เข้าจอ — ระหว่างนั้นเป็น skeleton เบาๆ กันจอกระตุก (CLS=0) · แต่ละ section ต่อคิวกันเป็นลูกโซ่ observer จึงไม่มีทางยิงก่อนเวลา · Googlebot เรนเดอร์ด้วยจอสูงเต็มหน้า → เก็บเนื้อหาครบทุกส่วน + `content-visibility:auto` ให้เบราว์เซอร์ข้ามการวาดส่วนที่มองไม่เห็น
- **LCP เร็วขึ้น**: ภาพใหญ่ใบแรกของ billboard ติด `fetchpriority=high` ภาพที่เหลือทั้งเว็บเป็น lazy ทั้งหมด ไม่แย่งเน็ตตอนเปิด
- **Lazy script**: hls.js โหลดเฉพาะตอนกดเล่นวิดีโอ HLS ครั้งแรก · supabase-js (Realtime) โหลดเฉพาะตอนเปิดตัวเล่น — หน้าแรกไม่มีสคริปต์ภายนอกเลย
- **URL ที่ Google เก็บได้จริง**: `?m=รหัสเรื่อง` (หน้าเรื่อง) และ `?a=slug` (บทความ) — ไม่ใช้ # ที่ Google มองไม่เห็น
- **Meta อัตโนมัติทุกหน้า**: เปิดดูเรื่องไหน `<title>` + description + **JSON-LD (VideoObject + Movie/TVSeries)** เปลี่ยนตามเรื่องนั้น · เปิดบทความได้ **JSON-LD Article** · ปิดแล้วคืนค่าเดิม
- **แท็ก SEO + หน้าหมวดหมู่ (?t=)**: แนวหนัง + คีย์เวิร์ดจากหลังบ้านแสดงเป็น #แท็กในหน้าเล่นและหน้ารายละเอียด — กดแล้วเปิด**หน้าหมวดหมู่** URL จริง `?t=แท็ก` (Google เก็บ index ได้) พร้อม meta + ItemList JSON-LD + แท็กใกล้เคียง · แตะชื่อเรื่อง/เรื่องย่อในหน้าเล่นเพื่อเปิดหน้ารายละเอียดได้เลย
- **บทความท้ายหน้าแรก**: เขียนจากหลังบ้าน → แสดงเป็นการ์ด (ลิงก์ `?a=` จริงที่บอทตามได้) + หน้าอ่านเต็ม
- **robots.txt + sitemap.xml**: robots.txt แถมมาแล้ว (แก้โดเมนข้างในให้ตรงของคุณ) ส่วน sitemap สร้างจากหลังบ้าน → เอาไฟล์ไปวางคู่ index.html → submit ใน [Google Search Console](https://search.google.com/search-console)

## 🛠 หลังบ้าน /admin

เปิด `https://โดเมนของคุณ/admin/` → กรอก **service_role key** (Supabase → Settings → API → `service_role`)

- คีย์เก็บใน sessionStorage เฉพาะแท็บ ปิดแท็บแล้วหาย — **ไม่ถูกฝังในโค้ด ไม่ขึ้น GitHub**
- **ห้าม**เอา service_role key ไปวางในไฟล์ใดๆ ของ repo เด็ดขาด
- หน้า /admin ใส่ `noindex` แล้ว + ถูกกันใน robots.txt — Google ไม่เก็บ

## 🔴 Live Layer + Watch Party (Supabase Realtime)

- **"N กำลังดูอยู่"** — ป้ายเรียลไทม์ในหน้าเล่น นับคนที่ดูเรื่องเดียวกันอยู่จริง (แสดงเมื่อ ≥2 คน)
- **อีโมจิลอย** — กดถูกใจ/แตะสองครั้ง หัวใจลอยขึ้นจอทุกคนที่ดูเรื่องเดียวกันพร้อมกัน
- **Watch Party** — ปุ่ม 👥 ในหน้าเล่น: สร้างห้อง → แชร์โค้ด/ลิงก์ (#party=CODE) → เล่น-หยุด-ข้ามตอน sync ตามโฮสต์ทุกจอ (sync เวลาใช้ได้กับวิดีโอ HLS/MP4)
- ใช้ Supabase Realtime (เปิดอยู่แล้วทุกโปรเจกต์) — ไม่ต้องสร้างตาราง ไม่ต้องตั้งค่าเพิ่ม
- ออฟไลน์/โหลดไลบรารีไม่ได้ → ระบบข้ามเงียบๆ เว็บทำงานปกติ

## 🧭 หน้า "สำรวจ" + 📸 การ์ดแชร์

- แท็บ "ชาร์ต" เปลี่ยนเป็น **"สำรวจ"**: แถวโปสเตอร์ไล่ตามแนวทุกหมวด (Netflix-style) + ชาร์ตความนิยมอยู่ล่างสุด
- ปุ่มแชร์ในหน้ารายละเอียด → **สร้างภาพการ์ด** โปสเตอร์+ชื่อ+คะแนน+โลโก้ (1080×1350) แชร์ลงโซเชียลหรือดาวน์โหลดอัตโนมัติ

## UX เหมือนแอปจริง

- **ปุ่มย้อนกลับ (Android/เบราว์เซอร์)** ทำงานเป็นลำดับ: ปิดคอมเมนต์ → ปิดหน้าต่างตอน → ปิดตัวเล่น → กลับแท็บก่อนหน้า → ออกจากเว็บ (ไม่หลุดออกจากเว็บกลางคัน)
- **โหลดแบบ skeleton** โปสเตอร์ shimmer ระหว่างรอข้อมูล ไม่มีจอขาว
- **จำตำแหน่ง scroll** ของแต่ละแท็บ สลับไปมาไม่เด้งขึ้นบนสุด
- **ปุ่ม "ลองใหม่"** บนแบนเนอร์เมื่อเชื่อมต่อฐานข้อมูลไม่ได้
- **ปุ่ม "ดูเพิ่ม"** ใต้กริดเมื่อมีหนังมากกว่าที่แสดง
- **Spinner ขณะบัฟเฟอร์** + **บอกเวลา (1:23 / 45:00) ขณะลากแถบเวลา**
- **ปุ่มลูกศรเปลี่ยนตอน** ข้างจอบนคอม (เสริมจากคีย์ ↑↓)
- **หน้าต่างเลือกตอนมีภาพพรีวิว** ทุกตอน (ใช้ field `thumbnail` จากตาราง episodes — ถ้าไม่มีใช้สีพื้นแทน) พร้อมชื่อตอน ความยาว เครื่องหมาย ✓ ตอนที่ดูแล้ว
- **ปุ่มเล่นกลางเมนูล่าง** วงกลมเรืองแสง pulse + ป้าย "เล่นเลย" — กดแล้วสุ่มเปิดเรื่องทันที

## ฟีเจอร์ตัวเล่น (เฉพาะทางสำหรับซีรีส์แนวตั้ง)

- **แตะ 1 ครั้ง** หยุด/เล่น · **แตะ 2 ครั้ง** กดถูกใจ (มีหัวใจเด้งตรงจุดที่แตะ)
- **กดค้าง** เร่งภาพ 2x (ปล่อยกลับความเร็วเดิม) — แบบเดียวกับ TikTok/ReelShort
- **ปุ่มปรับความเร็ว** 1x → 1.25x → 1.5x → 2x (จำค่าไว้)
- **ลากแถบเวลา** เพื่อเลื่อนไปยังจุดที่ต้องการ (วิดีโอ HLS/MP4)
- **จำเสียง/ความเร็ว** ครั้งต่อไปเปิดมาใช้ค่าเดิม
- **เล่นจบตอนอัตโนมัติ** เลื่อนไปตอนถัดไปเอง + จำวินาทีที่ดูค้าง
- **คีย์ลัดบนคอม**: ↑↓ เปลี่ยนตอน · Space หยุด/เล่น · M เสียง · Esc ปิด

## 📲 PWA — ติดตั้งเป็นแอป

เว็บติดตั้งลงหน้าจอโฮมได้เหมือนแอปจริง (เปิดเต็มจอ ไม่มีแถบเบราว์เซอร์ + โหลดเร็ว + เปิดได้แม้เน็ตหลุด)

- **Android/Chrome/Edge**: เด้งแบนเนอร์ "ติดตั้ง CineMax" อัตโนมัติ หรือกดที่ ของฉัน → ติดตั้งเป็นแอป
- **iPhone/Safari**: กดปุ่ม → มีวิธีบอกทีละขั้น (แชร์ → เพิ่มไปยังหน้าจอโฮม)
- **ออฟไลน์**: หน้าเว็บ/สไตล์/สคริปต์ถูก cache ไว้ เปิดได้แม้เน็ตหลุด (ตัววิดีโอกับข้อมูลยังต้องใช้เน็ต)

> ⚠️ PWA + Service Worker ทำงานเมื่อเปิดผ่าน **https://** (หรือ localhost) เท่านั้น
> เปิดไฟล์ตรงๆ แบบ `file://` จะไม่ติดตั้ง — ต้อง deploy ขึ้นโฮสต์/GitHub Pages ก่อน

## 🖱️ เล่นตัวอย่างตอน hover (คอม)

| URL | วิธีเล่น |

> แทนลิงก์ iframe — หาได้จาก Cloudflare Dashboard → Stream → วิดีโอ → HLS Manifest URL

## การ Deploy

เป็น static site ล้วน ไม่ต้อง build — อัปโหลดขึ้นที่ไหนก็ได้:

- **โฮสต์เดิม (Apache)**: อัปทั้งโฟลเดอร์ขึ้น web root หรือโฟลเดอร์ย่อย เปิดได้ทันที
- **GitHub → Railway** (ที่ใช้อยู่): push ขึ้น repo → Railway deploy อัตโนมัติ → ผู้ใช้ได้เวอร์ชันใหม่เองเมื่อรีเฟรช (service worker อัปเดตให้)
- ไม่ต้องใช้ PHP — หลังบ้านคือไฟล์ static `/admin/index.html` คุยกับ Supabase ตรงๆ

### สิ่งที่ต้องตรวจฝั่ง Cloudflare Stream

ถ้าวิดีโอไม่เล่น ให้เช็ก **Allowed Origins** ของ Stream:
Cloudflare Dashboard → Stream → Settings → Allowed Origins — ต้องมีโดเมนใหม่ที่ deploy (เช่น `romazeed1.info`, `*.github.io`) หรือปล่อยว่าง (อนุญาตทุกโดเมน)

### สิ่งที่ต้องตรวจฝั่ง Supabase

- ตาราง `movies` และ `episodes` ต้องเปิด RLS ให้ **anon อ่านได้** (SELECT) — ถ้าเว็บเดิมใช้งานได้อยู่แล้ว แปลว่าตั้งไว้ถูกแล้ว
- key ที่อยู่ใน `02-config.js` เป็น anon key (public read) เปิดเผยได้ตามดีไซน์ของ Supabase — **ห้าม**เอา service_role key มาใส่เด็ดขาด
